# Security policy — CBini OrquestrAI

🇺🇸 English · 🇧🇷 Resumo em português no fim.

## Reporting a vulnerability

Please report security problems **privately**: open this repository's **Security** tab and use **Report a vulnerability**
(GitHub private vulnerability reporting). Do not report them in issues, discussions or pull requests.

Include what you observed, high-level steps to reproduce and the impact you expect. Do not include real credentials, personal data or data
from systems you do not own or are not authorized to test.

We acknowledge reports and keep the reporter informed. We do not publish fixed response times.

## Scope

This repository contains public documentation only; the product source code is private. Reports about the product are welcome through the
same private channel. The public security model is in [docs/security-model.md](docs/security-model.md).
