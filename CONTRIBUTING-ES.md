# Cómo participar — CBini OrquestrAI

🇪🇸 **Español** · 🇧🇷 [Português](CONTRIBUTING-BR.md) · 🇺🇸 [English](CONTRIBUTING.md) · [README](README-ES.md)

CBini OrquestrAI **no se distribuye como software de código abierto**. Este repositorio contiene documentación pública; el código del
producto es privado, así que no hay código para clonar ni pull requests para enviar. Lo que más ayuda hoy es la crítica.

| Usted quiere… | Use |
|---|---|
| Cuestionar un supuesto de arquitectura | [Discusión de arquitectura](https://github.com/cristhianbini/CBini-OrquestrAI/discussions/2) o la plantilla de issue *Architecture feedback* |
| Hacer una pregunta | Discussions (Q&A) |
| Sugerir una capacidad o un caso de uso | Issue *Feature suggestion* |
| Reportar algo confuso en el producto o la documentación | *UX feedback* o *Documentation issue* |
| Mostrar interés en un piloto | Discussions, describiendo el tipo de organización y de proyecto (sin datos sensibles) |
| Reportar un problema de seguridad | **En privado, nunca en issues ni discusiones.** Vea [SECURITY.md](SECURITY.md). |

No publique credenciales, datos de clientes ni detalles de sistemas reales en issues o discusiones.
