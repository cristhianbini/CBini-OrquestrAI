# Como participar — CBini OrquestrAI

🇧🇷 **Português** · 🇺🇸 [English](CONTRIBUTING.md) · [README](README.pt-BR.md)

O CBini OrquestrAI **não é open source**. Este repositório guarda a documentação pública; o código do produto é privado, então não há código
para clonar nem pull request para enviar. O que mais ajuda hoje é crítica.

| Você quer… | Use |
|---|---|
| Questionar uma premissa da arquitetura | [Discussão de revisão de arquitetura](https://github.com/cristhianbini/CBini-OrquestrAI/discussions/2) ou o modelo de issue *Architecture feedback* |
| Fazer uma pergunta | Discussions (Q&A) |
| Sugerir uma capacidade ou caso de uso | Issue *Feature suggestion* |
| Relatar algo confuso no produto ou na documentação | *UX feedback* ou *Documentation issue* |
| Relatar um problema de segurança | **Em privado — nunca em issues ou discussões.** Veja o [SECURITY.md](SECURITY.md). |

Não publique credenciais, dados de clientes ou detalhes reais de sistemas em issues ou discussões.
