# Public roadmap — CBini OrquestrAI

🇺🇸 **English** · 🇧🇷 [Português](roadmap.pt-BR.md)

High-level direction only. No dates are promised; items move when they are proven, not when they are announced.

## Now
- **First full-stack path, end to end** — React + Vite + TypeScript, Express and SQLite: generated by the factory, running in its own
  isolated runtime, visible in a preview, changed through approved commands, with application data included in backups.
- **Project runtime validation** — lifecycle, resource limits, health and per-project network isolation for long-running applications.
- **Factory workflow refinement** — clearer project creation: choose a *type of project* instead of assembling individual components.

## Next
- **Reproducible self-hosted deployment** — full recovery proven on a clean server.
- **Guided installer** — one command on a clean server, then a web setup wizard (domain, administrator, two-factor authentication,
  providers, backup, diagnostics).
- **Public demos and documentation** — walkthroughs and clean screenshots.

## Later
- Additional validated stacks and databases on the same foundation.
- Governance features for larger teams.
- Broader integrations.
