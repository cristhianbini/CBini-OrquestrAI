# Taking part — CBini OrquestrAI

🇺🇸 **English** · 🇧🇷 [Português](CONTRIBUTING.pt-BR.md) · [README](README.md)

CBini OrquestrAI is **not open source**. This repository holds public documentation; the product code is private, so there is no code to
clone or pull requests to send. What helps most today is critique.

| You want to… | Use |
|---|---|
| Challenge an architectural assumption | [Architecture review discussion](https://github.com/cristhianbini/CBini-OrquestrAI/discussions/2) or the *Architecture feedback* issue template |
| Ask a question | Discussions (Q&A) |
| Suggest a capability or use case | *Feature suggestion* issue |
| Report something confusing in the product or the docs | *UX feedback* or *Documentation issue* |
| Report a security problem | **Privately — never in issues or discussions.** A private channel will be listed here once enabled. |

Please do not post credentials, customer data or real system details in issues or discussions.
